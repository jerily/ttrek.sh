# ttrek 1.2.0 is here: get the latest with self-update

**ttrek 1.2.0 is here!** The website and package registry now support **tags**.

Think of tags as labels on drawers: `web`, `json`, `xml`. They help you find
what you need, even when you don't know a package's name. Click a tag on the
website to find related packages, or try [searching for json](/search?q=json).

Already have ttrek? Open a terminal and get the latest version:

```sh
ttrek self-update
```

That's ttrek updating itself. Check your version afterward:

```sh
ttrek version
```
