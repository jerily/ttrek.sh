# ttrek 1.0.0 is now public

The first public release of **ttrek, version 1.0.0**, is here! ttrek is a
package manager for Tcl: find packages, install dependencies, and keep building.
You can get started at [ttrek.sh](https://ttrek.sh) and explore the code in the
[ttrek GitHub project](https://github.com/jerily/ttrek) and the
[public ttrek registry](https://github.com/jerily/ttrek-registry).

The team is just one person at the moment: **Neofytos Dimitriou**, ttrek's main
author. Most of the code was written from scratch, with AI helping in the final
stretch. Copyright in this work is held by **Neofytos Dimitriou and Jerily LTD**.
Thank you to **Kostiantyn Kushnir** for his help in developing ttrek.

We look forward to community contributions. Bug reports, testing on different
platforms, documentation improvements, package recipes, and code contributions
are all welcome. The project and registry are open for you to explore and help
shape what comes next.

This release is still a **proof of concept**. Please be patient as we work
through initial issues; with a one-person team, fixes may take time. Try it,
tell us what works and what doesn't, and help us make ttrek better for everyone.
