# ttrek 1.8.0 brings apt installation to Ubuntu

![A penguin pushes a parcel labeled “ttrek” through a mail slot in a terminal window.](images/ttrek-ubuntu-apt.jpg)

**With ttrek 1.8.0, Ubuntu users can install ttrek with apt and get future
versions through their usual system updates.** The package is available from
Jerily’s Personal Package Archive (PPA).

## Install with apt

On Ubuntu 26.04 LTS, add the archive and install ttrek.

```bash
sudo add-apt-repository ppa:jerily/ttrek
sudo apt install ttrek
```

Run `ttrek version` to check the installation. You only need to add the archive once.
