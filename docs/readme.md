# ttrek.sh documentation

[Project overview](../README.md)

These guides cover running and maintaining the website. Guides published on the
website live separately in `content/docs/`; blog posts live in `content/blog/`.

## Run the website

- [Setup](install.md): requirements, dependencies, browser assets and a local preview.
- [Local development](local-development.md): edit content, run local services and configure the direct server.
- [Package registry](registry.md): update recipes, configure sources and build search indexes.
- [Binary distributions](releases.md): serve downloads and manage release checksums.

## Maintain the website

- [Development](development.md): project principles, directory layout, runtime and request validation.
- [Testing](testing.md): application checks, local stack tests and optional browser tests.
- [Deployment](deployment.md): AWS builds, infrastructure and API Gateway configuration.
- [Security](security.md): trust boundaries, protections and current limitations.
